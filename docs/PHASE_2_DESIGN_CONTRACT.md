# Ankelba public website design contract

Audience: families exploring Ankelba and daycare teams applying for a workspace.

Primary action: apply for a daycare workspace. Existing users have clear role-specific sign-in links.

Visual direction: warm cream, deep green, muted sage and restrained ochre; editorial serif headings paired with the project's existing friendly sans-serif; generous spacing and existing childcare illustration. Use concrete product capabilities rather than invented metrics, reviews or customer logos.

Layout: split hero on desktop; stacked copy/artwork on mobile; concise feature explanations, a daily-care sequence, application invitation and expandable practical questions. Avoid dashboard-like density on the public page.

Interaction: brief entrance reveals, small press/hover feedback, page fades and dialog entrance/exit. Respect system reduced-motion preferences. Focus indicators remain visible; modal content uses labeled controls and a native focus-managed dialog. No continuous animation is required to understand content.

Verification: inspect desktop and 390px mobile layouts, verify no horizontal overflow, open/close the application dialog and check labels/focus. Evidence is saved in `docs/screenshots/phase2-landing-desktop.png` and `phase2-landing-mobile.png`.
